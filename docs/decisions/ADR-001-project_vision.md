# ADR stands for Architecture Decision Record - Why did we make this decision?

# ADR-001: Project Vision

## Status

Accepted

## Context

(Why does Project Aegis exist?) - Project Aegis exists to help disaster response organizations make timely, evidence-based decisions before flood events impact vulnerable communities.

## Decision

(What have we decided to build?) - Build a modular GeoAI decision support platform that combines geospatial evidence, flood risk assessment, and AI-generated explanations to support humanitarian decision-making.

## Users

(Who are we building for?) - We are building this for 

Primary Users
Government disaster management
NGOs
Emergency response teams

Secondary Users
Communities
Researchers
Policy makers

## Success Criteria

(How do we know Version 1 is successful?) - Version 1 is successful when a user can select a district, receive an evidence-backed flood risk assessment, visualize the affected areas, and understand why the system reached that conclusion.

## Engineering Principles

(List the principles we have defined.) - 
AI recommends. Evidence decides.
Build the right product before building the product right.
Software exists to support decisions, not display data.
Risk = Hazard × Exposure × Vulnerability.
Separate Data, Intelligence, and Presentation into independent layers.
Project Aegis will never replace human judgment, hide uncertainty, or present unsupported conclusions.
